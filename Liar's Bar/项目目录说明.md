# Liar's Bar 项目目录树说明

这份文档只介绍仓库中的代码目录结构，帮助接手项目的人快速知道代码放在哪里。

如果你想了解 Android App 最终形态，请查看 `ANDROID_HOST.md`。如果你想了解运行方式，请查看 `RUNNING.md`。如果你想了解协议字段，请查看 `PROTOCOL.md`。

## 顶层代码目录说明

### `apps/`

应用入口目录，负责平台适配和页面入口。

```text
apps/
├── web-client/
├── pc-host/
└── android-host/
```

- `web-client/`：Next.js 浏览器工程。用于调试 UI、查看效果、验证协议，并产出给 Android WebView 和外部浏览器玩家使用的静态页面。
- `pc-host/`：PC Edge/WebView2 候选宿主，用于开发和辅助验证。
- `android-host/`：最终优先的 Android 宿主。它用原生 Kotlin 启动本机 HTTP/WebSocket 主机，并通过 WebView 进入 App 内登录、房间和游戏界面。

### `apps/android-host/`

```text
apps/android-host/
├── android/
├── web-assets/
└── package.json
```

- `android/`：原生 Android 工程，包含 `MainActivity`、`NativeHostServer` 和 Gradle 配置。
- `web-assets/`：构建生成的静态页面资源目录，由 `scripts/sync-web-assets.mjs` 从 `apps/web-client/out` 同步而来，不手动维护。
- `package.json`：只保留 Android 构建脚本，不声明 Node 主机运行时依赖。

### `packages/`

共享能力目录，负责可复用代码。

```text
packages/
├── shared/
├── host-runtime/
└── ui/
```

- `shared/`：Web/PC 共享规则、数据类型、协议工具和局域网工具，不放 React UI。
- `host-runtime/`：PC 端 HTTP 静态托管 + WebSocket 调试主机运行时。
- `ui/`：Web 端 React UI 组件，包括登录页、房间页、对局页、牌面、弹窗、状态图标、卡牌尺寸 token 和全局主题 token。

Android 端不直接运行 `host-runtime`，因为这会重新引入 Node/JS runtime。Android 与 Web/PC 对齐的是协议、状态字段、页面资源和用户流程。

### `scripts/`

仓库级开发与构建脚本。

- `run-dev-browser.mjs`：浏览器开发模式入口，同时启动 `shared`、`ui` watch、开发 WebSocket 主机和 Next dev server。
- `sync-web-assets.mjs`：把 `apps/web-client/out` 同步到 PC/Android 宿主的静态资源目录。

## 当前关键源码入口

- `packages/ui/src/theme.ts`：全局主题变量源头，换色优先改这里。
- `packages/ui/src/styles.ts`：按钮、卡片、页面外壳等共享样式。
- `packages/ui/src/cardMetrics.ts`：局内卡牌和玩家席位尺寸 token。
- `packages/ui/src/StatusIcon.tsx`：玩家信息里的子弹、手牌图标。
- `packages/ui/src/PullToRefresh.tsx`：移动端下拉刷新状态组件。
- `apps/web-client/lib/client/WebSocketClient.ts`：浏览器 WebSocket 客户端，处理 `gameEvent`、重连和 `sync`。
- `packages/host-runtime/index.cjs`：PC 调试主机 HTTP/WebSocket 运行时。
- `apps/android-host/android/app/src/main/java/com/liarsbarandroidhost/NativeHostServer.kt`：Android 原生 HTTP/WebSocket 主机。

## 推荐阅读顺序

1. 先看 `ANDROID_HOST.md`，理解为什么最终 App 要保持轻内核。
2. 再看 `apps/android-host/android/app/src/main/java/com/liarsbarandroidhost/MainActivity.kt`，理解 App 如何启动主机和 WebView。
3. 再看 `apps/android-host/android/app/src/main/java/com/liarsbarandroidhost/NativeHostServer.kt`，理解 Android 原生主机如何托管页面和处理 WebSocket。
4. 再看 `apps/web-client/app/login`、`join`、`room`、`game`，理解浏览器和 WebView UI 流程。
5. 再看 `COLOR_SYSTEM.md` 和 `LANDSCAPE_UI_DESIGN.md`，理解当前主题和横屏局内 UI 约束。
6. 最后看 `packages/ui/` 和 `PROTOCOL.md`，理解 UI 组件和协议字段。
