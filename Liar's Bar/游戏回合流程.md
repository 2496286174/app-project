# 游戏回合流程

本文档记录了 Liar's Bar 游戏中两种模式的回合流程：骗子酒馆模式和德州扑克模式。

## 1. 骗子酒馆模式 (liarsBar)

### 1.1 游戏准备阶段
1. **创建房间**：房主创建游戏房间，设置游戏模式为骗子酒馆
2. **玩家加入**：最多8名玩家加入房间
3. **准备就绪**：所有玩家点击准备按钮
4. **游戏开始**：房主点击开始游戏

### 1.2 回合流程

#### 1.2.1 回合初始化
1. **洗牌**：根据玩家数量动态调整牌组大小
   - 基础配置：Q、K、A各6张，2张Joker
   - 扩展配置：每超过4人，每种点数牌增加2张，Joker增加1张/人
2. **发牌**：每位存活玩家获得5张手牌
3. **确定主牌**：随机从Q、K、A中选择一张作为主牌
4. **确定起始玩家**：从上一轮最后活动玩家开始，或选择第一个存活玩家

#### 1.2.2 玩家回合
1. **增加子弹**：当前玩家必须增加至少1颗子弹（最多8颗）
2. **出牌**：玩家选择1-3张牌，声明主牌数量
   - 出牌必须满足：1-3张牌，声明数量1-3
   - 玩家手牌减少相应数量
   - 创建出牌记录

#### 1.2.3 响应阶段
1. **下家行动**：当前玩家的下家必须先增加子弹，然后选择：
   - **质疑**：如果质疑成功（实际主牌数量小于声明数量），出牌者接受处决；如果质疑失败，质疑者接受处决
   - **相信**：相信出牌者，将出牌记录加入历史，轮到下家出牌

#### 1.2.4 处决阶段
1. **左轮判定**：被判定的玩家进行左轮判定，中弹概率 = 当前子弹数 / 最大子弹数
2. **结算**：处决结束后进入结算状态，等待房主点击"重新开始"

#### 1.2.5 游戏结束条件
1. **手牌出完**：玩家出完所有手牌直接获胜
2. **触发处决**：有人触发处决，结束游戏

## 2. 德州扑克模式 (texasHoldem)

### 2.1 游戏准备阶段
1. **创建房间**：房主创建游戏房间，设置游戏模式为德州扑克
2. **玩家加入**：最多8名玩家加入房间
3. **准备就绪**：所有玩家点击准备按钮
4. **游戏开始**：房主点击开始游戏

### 2.2 回合流程

#### 2.2.1 回合初始化
1. **洗牌**：使用标准52张扑克牌（不含Joker）
2. **发牌**：每位玩家获得2张底牌
3. **清理状态**：清空上一局公共牌、离场状态和本局待结算积分
4. **确定起始玩家**：从上一轮最后活动玩家开始，或选择第一个存活玩家

#### 2.2.2 预抽阶段
1. **摸1弃1**：每位存活玩家按顺序摸1张牌，再从自己的3张底牌中弃1张
2. **保留底牌**：预抽结束后，每位玩家仍保留2张底牌

#### 2.2.3 翻牌前行动
1. **玩家行动**：按顺时针顺序，玩家可以选择：
   - **增加子弹**：加至少1颗子弹，且必须大于本轮上一位继续玩家的加子弹数量
   - **提前开枪离场**：立即进行开枪判定，未中弹则安全退出本局，中弹则淘汰并记录扣1分给本局最终赢家

#### 2.2.4 翻牌阶段
1. **翻公共牌**：翻开3张公共牌
2. **玩家行动**：所有仍在场玩家按顺时针顺序行动，可继续加子弹或提前开枪离场

#### 2.2.5 转牌阶段
1. **翻第4张公共牌**
2. **玩家行动**：所有仍在场玩家按顺时针顺序行动，可继续加子弹或提前开枪离场

#### 2.2.6 河牌阶段
1. **翻第5张公共牌**
2. **玩家行动**：所有仍在场玩家按顺时针顺序行动，可继续加子弹或提前开枪离场

#### 2.2.7 摊牌阶段
1. **比较牌型**：所有仍在场玩家摊牌，比较牌型大小
2. **直接结算**：牌型最大者成为本局最终赢家；完全同牌型时按座位顺序最靠前者获胜；摊牌阶段不再开枪
3. **积分结算**：最终赢家获得所有最终仍在场失败玩家各1分；最终仍在场失败玩家各扣1分；提前开枪离场未中弹者不参与扣分；提前开枪中弹者扣1分给最终赢家

#### 2.2.8 本局提前结束
1. **唯一在场玩家**：如果摊牌前只剩一名玩家仍在场，该玩家直接成为本局最终赢家
2. **积分结算**：该玩家获得本局中所有提前开枪中弹玩家的积分；安全离场玩家不参与扣分

#### 2.2.9 游戏结束条件
1. **存活条件**：场上只剩一名存活玩家时，游戏结束
2. **积分条件**：也可以按房间约定采用固定局数或积分目标结束游戏

## 3. 通用规则

### 3.1 子弹系统
- **增加子弹**：每个回合开始时，玩家必须增加至少1颗子弹
- **子弹上限**：每回合最多增加8颗子弹
- **开枪概率**：当前子弹数越多，中弹概率越高

### 3.2 处决机制
- **左轮判定**：按当前子弹数进行中弹判定
- **幸存标记**：成功幸存的玩家获得"处决幸存"标记

### 3.3 游戏状态
- **waiting**：等待玩家加入
- **playing**：游戏进行中
- **ended**：游戏结束，等待房主重新开始

## 4. 代码实现参考

### 4.1 骗子酒馆模式
- 实现文件：`packages/shared/game-logic/LiarsBarGame.ts`
- 核心方法：
  - `startGame()`：开始游戏
  - `playCards()`：玩家出牌
  - `challenge()`：玩家质疑
  - `trust()`：玩家相信
  - `addBullets()`：增加子弹

  - `texasHoldemRound`：德州扑克回合阶段管理

## 5. 流程图

### 5.1 骗子酒馆模式流程图
1. 游戏开始 → 初始化牌组 → 发牌 → 确定主牌
2. 当前玩家回合 → 增加子弹 → 出牌
3. 下家回合 → 增加子弹 → 选择质疑/相信
   - 质疑 → 验证出牌 → 处决判定
   - 相信 → 轮到下家出牌
4. 检查游戏结束条件 → 是则游戏结束，否则继续回合

### 5.2 德州扑克模式流程图
1. 游戏开始 → 初始化牌组 → 发底牌 → 预抽摸1弃1
2. 翻牌前行动 → 加子弹继续或提前开枪离场
3. 翻牌阶段 → 翻3张公共牌 → 玩家行动
4. 转牌阶段 → 翻第4张公共牌 → 玩家行动
5. 河牌阶段 → 翻第5张公共牌 → 玩家行动
6. 摊牌阶段 → 比较牌型 → 最大牌型者结算积分
7. 检查游戏结束条件 → 是则游戏结束，否则开始新回合
